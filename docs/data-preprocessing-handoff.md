## 공통 ID와 모델 입력

CSR은 사용자 행 × 곡 열이고 값은 정제된 train 청취 횟수다. `items.parquet`의 `train_listener_count`는 곡을 들은 고유 학습 사용자 수다. 모델이 log 변환·confidence·인기도 보정을 적용할 때 이 두 원시 값을 각각 사용한다. 관측되지 않은 좌표는 선호 여부를 알 수 없는 쌍이다.

모델 내부 ID를 바꾸면 `users.parquet`와 `items.parquet`의 공통 ID로 되돌리는 매핑을 보존한다. 공유 추천 결과의 행과 열은 0 기반 `user_idx`와 `item_idx`로 복원한다. 선정 CSV의 `user_index`는 점검용 표시 번호다.

## 평가 기준

후보는 전체 train 카탈로그에서 해당 사용자의 train 기청취곡을 뺀 집합이다. 정답은 기간별 고유 청취곡 중 후보에 속하는 곡이다. 학습 이력 있음·정답 ≥1개·후보 ≥10개를 validation과 test에 따로 적용했다. validation은 3,922명·193,323쌍, test는 3,852명·201,203쌍이다. test에서도 원래 train 이력만 후보에서 제외한다.

사용자별 추천 10곡과 정답의 교집합을 정답 수로 나누고 사용자 평균을 내면 macro Recall@10이다. 사용자별 추천 10곡의 `train_listener_count` 평균을 구하고 다시 사용자 평균을 내면 ARP다. 팀 자료조사 통합본의 validation 선택안은 각 방식의 보정 전 설정을 고른 뒤, 해당 기준 모델 Recall@10의 95% 이상을 유지하는 보정 설정 중 ARP가 가장 낮은 설정을 선택하는 것이다. 보정 강도 0도 포함한다. 확정한 설정과 최초 train을 유지해 test를 평가한다.
