# 팀 공유용 데이터 점검 설명 초안

2026-11-07에 공통 데이터 담당 범위의 원본 확인과 전처리 기준 정리를 완료했다. 모델 담당자에게 전달할 설명 초안이며 최종 전처리 데이터는 아직 없다.

현재 로컬 전달본의 SHA256, 9,350,628행, 5,000명, 네 컬럼, UTC 2026-08-17~2026-10-11의 56일을 직접 확인했다. 결측·빈 이름·기간 밖 행은 없고, 원본과 부속 다섯 파일의 실행 전후 해시는 일치했다. 전체 공식 덤프나 후보 사용자 전체를 다시 내려받거나 검증하지는 않았다.

이번 고정 규칙은 NFC와 유니코드 공백 정리이며 아티스트·제목 튜플로 곡을 구분한다. 대소문자·구두점·라이브·리믹스·리마스터 표기는 유지한다. 동일 사용자·동일 시각·동일 정규화 곡만 한 사건으로 집계하고 다른 시각의 반복 청취는 유지한다. 과도한 청취량과 비음악 의심 제목은 발견했으나 이 네 컬럼만으로 확정할 수 없어 자동 삭제하지 않는다. 저인기 곡 필터나 사용자 재표본 추출도 하지 않는다.

임시 진단 결과는 사건 8,813,053건, 전체 이름 튜플 1,856,311개, 학습 항목 1,525,005개다. 기존 수치와는 사건 4건·전체 튜플 40개 차이가 난다. 기존 공백 규칙을 같은 원본에 다시 적용하면 과거 수치가 재현되므로 새 규칙의 차이로 설명된다. 선정 CSV의 학습 고유곡 수가 달라진 사용자는 8명이며, 원래 사용자와 순서는 유지한다. 최종 통계는 패키지 파일 생성 후 다시 검증한다.

학습은 `[8/17,9/28)`, 검증은 `[9/28,10/5)`, 테스트는 `[10/5,10/12)`이며 모두 2026년 UTC다. 카탈로그·ID·청취 횟수·인기도는 학습에서만 만들고 검증 후에도 학습 기간을 고정한다. 인기도는 곡별 고유 학습 청취자 수다.

평가 후보는 전체 학습 곡에서 사용자 자신의 학습 청취곡을 뺀 집합이다. 정답은 해당 평가 기간에 들은 곡 중 후보에 속한 고유 곡이다. 학습 이력·정답 1개 이상·후보 10개 이상을 만족하는 사용자를 기간별로 따로 정한다. 임시 진단에서는 검증 3,922명/193,323쌍, 테스트 3,852명/201,203쌍이다. 신규 곡 제외 사건은 검증 228,684건, 테스트 255,471건이다. 성능 지표를 계산한 결과는 아니다.

패키지에 공통 train_interactions, 원시 횟수 CSR, users/items 매핑, 기간별 정답과 사용자 목록, manifest를 생성할 예정이다. 행렬 방향은 사용자×곡이며 ID는 학습 기준 0부터 시작하는 결정적 연속 정수다. 현재 CSV의 1부터 시작하는 user_index는 공통 user_idx가 아니다. 모델 내부에서 ID를 바꾸면 공유 출력 전에 공통 ID로 복원해야 한다. 로그값·confidence·IPS 가중치는 공통 파일에 저장하지 않으므로 각 모델 담당자가 원시 횟수와 인기도로 계산한다.

모델 담당자는 전체 약 152만 항목과 희소 입력 지원, 보정 실험 구성·가중 손실 지원 여부, 점수 동률·이웃 부족 처리, 탐색 설정과 방법론 문헌을 확인해야 한다. 이 항목들은 아직 팀 합의로 확정하지 않았다. 공통 후보 제한이나 인기곡 필터를 임의로 넣지 않는다. 모델 결정과 독립적으로 공통 데이터 생성 준비는 진행할 수 있다.

실행 가능한 점검 코드·환경과 [상세 결과](../reports/raw-data-audit.md), [규칙](preprocessing-plan.md), [전달 규격](data-contract.md)을 작성했다. 실제 데이터 공유 공간과 최종 버전·해시는 생성 후 기록한다. 모델 구현·보정 가중치 계산·지표 코드·추천 결과·UI는 이번 완료 범위에 없다.

11월 8일 추가 검사에서는 학습 신호가 존재함을 확인했고, 단독 청취 곡의 유사도 동률·동일 시각 다곡 기록·거의 같은 두 사용자 이력·dense 배열 메모리 위험을 기록했다. 원래 표본과 전처리 규칙은 유지했다. 모델의 좋은 성능을 보장한 것은 아니며, 전체 카탈로그 실행 점검과 confidence·동률 처리는 모델 담당자가 확인해야 한다. 근거와 영향 규모는 [추가 타당성 검토](../reports/model-readiness-review.md)에 있다.
