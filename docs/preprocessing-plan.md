# 공통 전처리 기준

2026-11-07 기준 원본 점검과 전달 규격 설계까지 완료. 최종 전처리 파일, 모델, 보정 가중치, 성능 지표는 아직 만들지 않았다. 실제 통계는 [원본 점검 보고서](../reports/raw-data-audit.md)를 기준으로 한다.

## 근거와 적용 범위

로컬 원본은 9,350,628행·5,000명이며 요청된 SHA256과 일치한다. 데이터에 저장된 TIMESTAMP는 시간대 없는 값이다. 부속 README가 명시한 UTC로 해석하고 로컬 시간대 변환 없이 분할한다. 전체 덤프나 사용자를 다시 수집할 필요는 없다.

| 결측·빈 이름 | 필수 필드 NULL, 정규화 후 빈 이름은 별도 제외 사유로 집계 | 실제 결측·빈 이름은 0건 | 향후 발생 시 임의 대체하지 않음 |
| 시간 범위 | 지정한 56일만 허용, 범위 밖은 별도 사유로 집계 | 현재 범위 밖 0건 | UTC 시작 포함·종료 미포함 |

| 표시 이름 | 보존된 학습 사건만으로 원문 이름 쌍 대표 선택 | 미래 표기·빈도가 출력 및 ID에 영향 주지 않음 | 아래 결정적 선택 절차와 계약 준수 |
| 과도한 활동 | 건수로 자동 삭제·상한 절삭하지 않음 | 진단 일 최대 2,406건, 고유 시각 2,347개; 곡 길이 없음 | 비정상 여부 미확정, 제한 표본과 한계 기록 |
| 비음악 의심 | 문자열 검색은 검토 신호만 기록 | 4,783건 신호에 Glass Animals·Toby Fox 등의 제목도 포함 | 키워드만으로 삭제하면 오탐 가능; 현 단계 보존 |
| 저인기·사용자 | 인기도 필터·k-core·최소 곡 수 재적용·재표본 추출 없음 | 표본과 저인기 곡 연구 목적 보존 | 미래 활동으로 사용자 선정하지 않음 |

공백 목록은 U+0009~000D, U+001C~0020, U+0085, U+00A0, U+1680, U+2000~200A, U+2028~2029, U+202F, U+205F, U+3000이다. U+200B와 U+FEFF는 이 목록의 공백이 아니므로 자동 제거하지 않는다.

동일 사건에 원문 표기가 여러 개면 원문 (artist_name, recording_name)의 UTF-8 바이트 오름차순 첫 쌍을 남긴다. 이 학습 사건들에서 정규화 키별 원문 쌍 빈도가 가장 큰 쌍을 표시 대표로 사용하며, 동률은 같은 바이트 정렬로 결정한다. 원문 쌍을 함께 선택해 서로 관측되지 않은 아티스트·제목 조합을 만들지 않는다. items에 대표 원문과 정규화 키를 구분해 보존하고, 다른 표기는 별도 데이터 측 alias 파일로 보존할 수 있다.

## 과거 수치와 다른 이유

기존 로컬 `analyze_window_audit.py`는 `NFC(regexp_replace(trim(s), '\s+', ' ', 'g'))`를 사용했다. 이번 규칙은 유니코드 공백을 명시적으로 축약하고 마지막에 trim한다. 과거 규칙을 같은 원본에 다시 적용해 8,813,057행·전체 1,856,351항목·학습 1,525,029항목을 재현했다. 새 규칙의 진단값은 8,813,053행·전체 1,856,311항목·학습 1,525,005항목이다. 차이는 보고서의 legacy_rule_differences 표로 추적한다.

선정 CSV의 train_unique_tracks와 새 학습 집계가 다른 사용자는 8명이다. 과거 규칙으로는 차이가 없으며 파일 손상 근거가 아니다. 원래 5,000명을 유지하고 해당 CSV나 선정 조건을 새로 쓰지 않는다. 현재 진단에서 모든 사용자의 학습 이력이 남고 최소 학습 고유 항목 수는 10개다. 이후 정제 규칙으로 학습 이력이 0이 되면 그 사용자만 학습 ID 및 평가 대상에서 제외하고 원래 표본 ID·사유를 데이터 측 제외 기록에 남긴다. 다른 사용자로 보충하지 않는다. 1~9곡으로 줄어든 사용자는 유지한다.

## 분할과 누출 방지

| 구간 | UTC 시작 포함 | UTC 종료 미포함 |
| --- | --- | --- |
| train | 2026-08-17 00:00 | 2026-09-28 00:00 |
| validation | 2026-09-28 00:00 | 2026-10-05 00:00 |
| test | 2026-10-05 00:00 | 2026-10-12 00:00 |

정규화는 학습되는 변환이 없는 고정 규칙이다. 중복 키는 시각을 포함하므로 분할 간 사건을 합치지 않는다. ID·카탈로그·대표 이름·청취 횟수·고유 청취자 인기도는 train에서만 만든다. 검증을 마친 뒤에도 학습 기간을 유지하며 validation을 합쳐 재학습하지 않는다. 정제 임계값이나 규칙을 검증·테스트 모델 성능으로 고르지 않는다.

평가 후보·정답·사용자 및 모델 출력 복원 규칙은 [데이터 계약](data-contract.md)에 고정했다. 사용자별 전체 후보 목록을 물리적으로 전개하지 않고 학습 카탈로그와 학습 이력으로 재구성한다. 후보 표본 추출이나 인기 상위 곡 제한을 도입하지 않는다.
