# ListenBrainz 전체 학습·평가 패키지 생성과 독립 검증

## 원본과 시간 분할

MetaBrainz Foundation / ListenBrainz 덤프 2723의 8주 전달본을 사용했다. 동봉 manifest의 스냅샷은 2026-10-15 00:00:02.588811 UTC이며 이용 조건은 동봉 `COPYING`의 CC0 1.0 Universal이다. 여섯 입력 파일은 [고정 입력 기준](../config/raw-input-reference.toml), [기존 정제 실행](cleaning-split-validation.md), [시간 분할 검증](temporal-split-review.md)과 일치했다. 생성 및 독립 검증 각각의 실행 전후에 원본 여섯 파일이 동일했다.

Parquet은 `user_id BIGINT`, `listened_at TIMESTAMP`, `artist_name VARCHAR`, `recording_name VARCHAR` 순서다. 시각은 시간대 표기 없는 마이크로초 정밀도로 저장되어 동봉 명세대로 UTC로 해석했다. 선정 CSV의 5,000명과 원본 사용자 집합의 양방향 차이는 각각 0명이다. 5,000명 전원에게 정제된 train 이력이 남았다. 재검사에서 표본 내부의 해시 순위 위반은 0명, 기존 공백 규칙으로 계산한 train 고유곡 수의 CSV 불일치는 0명, 현재 규칙에서는 8명이었다. 고정 표본과 선정 CSV를 그대로 사용했다.

| 분할 | 2026년 UTC [시작, 끝), 각 00:00 | 중복 전 유효 행 | 생성 manifest 사건 | 독립 대조 사건 | 시간 분할 보고서 사건 | 생성 − 보고서 |
| --- | --- | ---: | ---: | ---: | ---: | ---: |
| train | [08-17, 09-28) | 7,018,319 | 6,623,584 | 6,623,584 | 6,623,584 | 0 |
| validation | [09-28, 10-05) | 1,178,452 | 1,104,514 | 1,104,514 | 1,104,514 | 0 |
| test | [10-05, 10-12) | 1,153,857 | 1,084,955 | 1,084,955 | 1,084,955 | 0 |

원본 9,350,628행에서 필수값 NULL, 기간 밖, 정규화 후 빈 이름으로 제외한 행은 우선순위별로 각 0행이다. 중복 초과 537,575행(원본의 5.75%)을 제외해 8,813,053건을 보존했다. 기간별 중복 초과는 train 394,735행, validation 73,938행, test 68,902행이다.

이름 필드 각각에 NFC와 고정 공백 29종 축약·trim을 적용했다. 같은 사용자·시각·정규화 키에서 UTF-8 바이트 순으로 가장 앞선 원문 쌍을 남기며, 다른 시각의 반복과 같은 시각의 다른 곡은 보존한다. 대표 표시명은 정제 train에서 가장 자주 나타난 원문 쌍이다. 동률은 UTF-8 바이트 순으로 해소한다. 이전 공백 규칙의 train 6,623,588건은 동일 원본에서 재현된 과거 값이며 현재 규칙이 4건 적다. [전처리 계획](../docs/preprocessing-plan.md) · [과거 공백 규칙 재현](raw-data-audit.md)

규칙별 전후 변화, 원문 키와 정규화 키 비교, 고유 청취자 구간별 중복 영향, 고활동·이상 문자 진단은 시간 분할 검증의 표를 기준으로 한다. 같은 유효 train 행에서 정규화로 곡 키 166개, 사용자·곡 쌍 38개가 줄었다. 학습곡 1,525,005개 중 청취자 1명인 곡 1,204,318개(78.97%)를 보존했다. 동시각 10곡 이상인 2,146사건을 포함해 품질 신호로 삭제한 사건과 병합한 계정은 각각 0이다. [정제 규칙별 영향표와 분모](temporal-split-review.md#정제-규칙별-판단)

## 저장 파일 전체 대조

생성기와 별도 DuckDB 작업 공간에서 원본의 정규화 키와 UTC 구간을 다시 계산했다. 사건별 원문 최소 쌍과 학습 대표 이름을 산출하고, train의 사용자·곡별 고유 시각 사건을 세었다. 곡별 고유 청취자 수는 원본 기반 train 사건에서 `COUNT(DISTINCT user_id)`로 구했다. 생성기의 `train_pairs` 및 `targets` 관계를 사용하지 않았다. 검증에는 [독립 검사 코드](../scripts/validate_dataset.py)와 [독립 사건 기준](../scripts/review_temporal_split.py)을 사용했다.

| 대조 대상 | 실측 범위 | 누락 / 초과 |
| --- | --- | --- |
| users.parquet | 5,000명, 원본 ID 오름차순과 0 기반 매핑 | 0 / 0 |
| items.parquet | 1,525,005곡, 키·ID·표시명·고유 청취자 수 | 0 / 0 |
| train_interactions.parquet | 2,739,292개 고유 좌표와 양의 횟수 | 0 / 0 |
| validation_targets.parquet | 193,323쌍 | 0 / 0 |
| validation_users.csv | 3,922명, 독립 기대 사용자와 저장 정답의 고유 사용자 각각 대조 | 0 / 0 (두 대조 모두) |
| test_targets.parquet | 201,203쌍 | 0 / 0 |
| test_users.csv | 3,852명, 독립 기대 사용자와 저장 정답의 고유 사용자 각각 대조 | 0 / 0 (두 대조 모두) |

Parquet 5개를 Arrow로 순서대로 읽어 열 순서·자료형·필수 필드·NULL·ZSTD·배치 경계의 정렬과 ID 중복을 검사했다. CSV 2개는 헤더, 10진 int32, 정렬과 유일성을 확인했다. 기대 행과의 일치로 ID 연속성, 매핑 및 파일 간 참조가 확인됐다. CSR은 `(5,000, 1,525,005)`, nnz 2,739,292개, 청취 횟수 합 6,623,584건이다. `data`는 int64, `indices`·`indptr`는 int32다. SciPy로 다시 열어 행 포인터·인덱스 범위·행별 오름차순을 확인했다. 명시적 0, 중복 열, 원본 기반 좌표·값 불일치는 각각 0이다. matrix density는 0.035925%다.

## 평가 사용자와 제외 규모

기간별 고유 청취곡에서 학습 카탈로그에 있고 사용자가 train에서 듣지 않은 곡을 골랐다. train 이력이 있고 정답이 하나 이상이며 후보가 10개 이상인 사용자를 기간마다 선정했다. 가장 적은 후보 수는 1,513,129개였다. test는 최초 train 이력만 사용했고 두 기간 정답의 공통 사용자·곡 쌍 18,279개가 양쪽에 남았다.

| 기간 | 분류 | 사건 / 전체 기간 사건 | 고유 곡 / 전체 기간 곡 | 고유 사용자·곡 쌍 / 전체 기간 쌍 | 영향 사용자 / 기간 활동 사용자 |
| --- | --- | ---: | ---: | ---: | ---: |
| validation | 학습 밖 신규 곡 | 228,684 / 1,104,514 | 168,926 / 418,374 | 174,308 / 596,553 | 3,792 / 4,205 |
| validation | 학습 기청취곡 | 617,108 / 1,104,514 | 164,659 / 418,374 | 228,922 / 596,553 | 3,813 / 4,205 |
| test | 학습 밖 신규 곡 | 255,471 / 1,084,955 | 180,246 / 418,776 | 187,636 / 594,266 | 3,764 / 4,114 |
| test | 학습 기청취곡 | 550,599 / 1,084,955 | 148,304 / 418,776 | 205,427 / 594,266 | 3,639 / 4,114 |

분류는 사용자·곡 쌍과 사건을 배타적으로 나눈다. 고유 곡과 사용자 집합은 분류별로 겹칠 수 있다. validation에서 후보에 해당하는 258,722사건을 193,323쌍으로 접어 반복 사건 65,399건을 정답 집계에서 줄였다. test는 278,885사건에서 201,203쌍을 만들었고 반복 77,682건을 줄였다. 후보 10개 미만으로 제외된 정답 쌍은 두 기간 모두 0이다.

| 사용자 제외 우선순위 | validation / 선정 5,000명 | test / 선정 5,000명 |
| --- | ---: | ---: |
| 학습 이력 없음 | 0 | 0 |
| 기간 활동 없음 | 795 | 886 |
| 후보에 해당하는 정답 없음 | 283 | 262 |
| 후보 10개 미만 | 0 | 0 |
| 평가 포함 | 3,922 | 3,852 |

활동 사용자만 분모로 두면 정답이 없어 제외된 사용자는 validation 283/4,205명, test 262/4,114명이다. 학습곡 1,525,005개, 고유 학습 쌍 2,739,292개, 기간별 평가 사용자·정답 및 전체 정제 사건은 [원본 점검 참고 집계](raw-data-audit.md)와 모두 일치했다.
