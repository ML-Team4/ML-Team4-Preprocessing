# CSV 데이터셋 생성과 검증

`datasets/listenbrainz-preprocessing.zip`은 공통 학습·평가 CSV 7개와 manifest·README·COPYING을 제공한다. CSV 계약은 2.0.0이다. 원본 8주에 공통 정제·시간 분할을 적용하며, 배포 이름 정리로 CSV 값과 순서는 바꾸지 않는다.

## 전달 형식과 검증 범위

- 학습 청취 횟수, 사용자·곡 매핑, 검증·테스트 정답과 평가 사용자 목록을 CSV 7개로 제공한다. 사용자가 찾기 쉬운 폴더 경로를 README와 인수인계 문서에 안내한다.
- 헤더와 UTF-8 BOM을 쓰고 정수 자료형을 명시한다. CSV의 쉼표·따옴표·개행, 한국어·악센트, 실제 NA·NULL 문자열을 보존한다.
- 모델이 사용할 SciPy CSR은 학습 CSV에서 메모리에 구성한다. 팀 인수인계 문서는 CSV 로딩·행렬 구성·평가 정답 예제를 제공하고, 패키지 README에는 곡명 조회를 안내한다.
- 각 CSV의 모든 행을 생성 관계 및 원본에서 독립적으로 계산한 기대값과 대조한다. 무결성·자료형·집계 기록은 manifest에 보관한다.

| items.csv | 1,525,005 | 0 |

| test_targets.csv | 201,203 | 0 |

학습 CSV는 고유 사용자·곡 쌍 2,739,292행이며 listen_count 합계는 6,623,584건이다. 검증·테스트 정답은 각 기간의 평가 대상 사용자에 대한 고유 정답 쌍이다. 데이터의 행 단위와 제외 규칙은 [공통 계약](../docs/data-contract.md)을 따른다.

CSV 7개는 검증된 원본 기반 패키지의 모든 값·순서와도 불일치 0건이었다. 실제 파일로 학습 행렬 크기 (5000, 1525005), 비제로 2,739,292개와 곡명·아티스트명 조회를 확인했다.

회귀 테스트 26개가 통과했다. CSV 특수문자·개행·결측값으로 오인하기 쉬운 이름·큰 정수 ID·빈 데이터·BOM 누락, 시간 분할·미래 정보 누수, 잘못된 좌표·횟수·metadata, 실패 후 재시도와 동시 생성을 검사했다. 기존 계약의 저장 파일을 다시 검증하는 경로도 확인했다.

## 직접 확인하는 방법

저장소 루트에서 다음 명령으로 현재 CSV 전달본을 독립 검증한다. matches가 true이고 모든 누락·초과가 0이면 통과다.

```bash
.venv/bin/python scripts/validate_dataset.py --config config/paths.example.toml \
  --package "datasets/listenbrainz-preprocessing"
```

CSV 전체 로딩·학습 행렬·평가 연결은 인수인계 문서에서 확인한다. [팀원용 로딩 예제](../docs/data-preprocessing-handoff.md#폴더-한-곳을-지정하는-실행-예제)

큰 학습 CSV와 곡 CSV는 Excel 한 시트의 행 한도를 넘으므로 전체 행을 사용하는 분석은 CSV 파서로 수행한다.

CSV 전달 형식 변경은 [Issue #11](https://github.com/ML-Team4/ML-Team4-Preprocessing/issues/11)에 기록했다.

## 원본 기반 독립 검증의 근거

생성기의 train_pairs·targets 관계를 사용하지 않고 원본 네 컬럼에서 별도로 사건 키·UTC 구간·학습 좌표·대표 원문 이름·고유 청취자 수와 두 기간의 정답을 계산한다. 사용자 집합과 선정 CSV의 차이는 양방향 0명이다. 선정 파일의 과거 공백 규칙에 따른 train 고유곡 수는 일치하고, 현행 정규화에서는 8명에게 차이가 있어 선정 파일을 그대로 보존한다.

원본 9,350,628행에서 중복 초과 537,575행을 제외해 8,813,053사건을 남겼다. 결측·기간 밖·빈 이름 제외는 각 0행이다. train/validation/test의 중복 초과는 각각 394,735/73,938/68,902행이다. 동시각 10곡 이상인 2,146사건을 포함한 품질 신호로 삭제한 사건·병합한 계정은 각 0건이다.

학습 행렬은 사용자 행 × 곡 열 `(5000, 1525005)`이고, 고유 좌표 2,739,292개·횟수 합 6,623,584건이다. 가장 적은 후보 수는 1,513,129개다. 두 평가 기간의 공통 사용자·곡 정답 18,279쌍을 양쪽에 보존한다. validation 후보 258,722사건은 193,323쌍, test 후보 278,885사건은 201,203쌍으로 평가한다. 학습 이력 없음/기간 활동 없음/정답 없음/후보 10개 미만 제외 사용자는 validation `0/795/283/0`, test `0/886/262/0`명이다. 자세한 신규곡·기청취곡 제외표와 분모는 [시간 분할 검증](temporal-split-review.md)과 [EDA](listening-eda.md)에 있다.

독립 Python 정규화로 전체 원본을 재집계한 학습·평가 파일도 차이 0건이었다. 과거 Parquet·NPZ 전달 계약의 검증 기능은 호환성 검사에 유지한다. 여분 CSR 배열 원소와 metadata 오류 주입 48건을 거부했고 경계 사례 8건·int64 CSR 인덱스를 허용했다.

배포 원본 대조와 다운로드본 재현 결과는 [배포 검증 보고서](distribution-validation.md)에 기록한다.
